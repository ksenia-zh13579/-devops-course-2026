# Git vs SVN — подробное сравнение

1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
В Git ветка — это всего лишь указатель на определенный коммит, а создание и переключение между ветками занимает доли секунды. в SVN же ветка создается как полная копия директории на сервере, а это более медленная операция, поэтому веток обычно меньше, и они создаются для крупных задач.

2. Можно ли в SVN сделать коммит без интернета? Почему?
Нет, поскольку в SVN коммит отправляется на центральный сервер сразу, а для этого требуется сетевое соединение и права на запись.

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
SVN чаще всего предпочитают использовать в корпоративныж проектах со строгим контролем (модель SVN «один сервер — одна истина» с четким поэкземплярным контролем доступа проще для администрирования и аудита), в проектах с большими бинарными файлами (SVN исторически лучше справляется с хранением больших неделимых файлов), а также для проектов, где важна максимальная простота и не предполагается активное ветвление.
