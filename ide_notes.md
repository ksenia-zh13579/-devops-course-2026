# Работа с Git через IDE VS через CLI (терминал)

## Удобнее делать через UI в IDE:

- Следить за расположением веток в графе и за текущим положением в ветке
- Перемещаться с ветки на ветку
- Публиковать репозиторий

## Удобнее через CLI:

- Выполнять комплексные действия (rebase, откат на несколько коммитов назад и т.д.)
